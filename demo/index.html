Coverage is the number of trial intervals containing the known answer. Three to ten trials cannot establish 95% coverage or RNG independence. Repeated streams deliberately violate the interval's independence assumption.

Explain the mathematics

π: generate (x,y) uniformly in the unit square; count H points with x²+y² ≤ 1. Then π̂ = 4H/N. For sample values Z = 4 or 0, the displayed approximate 95% interval is mean(Z) ± 1.96√(s²/N), where s² is sample variance with denominator N−1. This describes repeated-sampling coverage, not a 95% probability that a fixed π moves inside a particular interval.

Integral: f(x) = (x₁² + … + x_d²)/d on [0,1]^d; the exact integral is 1/3 and independent-sample estimator variance is 4/(45dN). It is a simple separable validation case, not a demonstration of overcoming the curse of dimensionality.

Read the comparison carefully. CPU uses Mersenne Twister; GPU uses Philox, so this is not a matched-RNG comparison. Warmups and process launch are excluded from median timings. MPI runs locally.

A quick demo, not publication-grade. Short trials are sensitive to laptop scheduling and frequency changes; observed speedup can exceed ideal worker scaling and efficiency can exceed 100%. Values are shown without capping. Speedup uses median timing; the CI describes only the last trial and its estimate, not an aggregate across trials.
